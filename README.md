# 星夜騎士 · Starry Night 3D Impasto

一個以單一 HTML 檔實作、無任何外部圖片或 3D 模型素材的 **WebGL2 即時 3D 油畫世界**。

- **線上遊玩（GitHub Pages）**：[https://unkoalatw.github.io/starry-night-3d/starry_night_3d.html](https://unkoalatw.github.io/starry-night-3d/starry_night_3d.html)
- **單一核心檔案**：[`starry_night_3d.html`](starry_night_3d.html)

## 特色
- **純 3D Instanced Quad 油畫筆觸著色器**：桌面版約 718K 筆（手機約 290K 筆），固定在 3D 世界座標與方向上，GLSL 繪製固定 8 條刷毛紋理、厚塗受光立體感、螢幕大小上下限、距離漸隱與防閃爍層間距。
- **《星夜》光影與世界**：氣流流動的渦流夜空、金橘色滿月與同心光環、放射狀金黃星芒、三層實心剪影山脈（最遠層帶積雪）、夜間低頭朝向一致的向日葵花田、環形小徑、旋轉風車、亮窗小屋、教堂尖塔村莊、柏樹、搖曳麥田、具即時倒影的河、石拱橋、岩壁瀑布，以及鏡頭周圍即時生成的細草。
- **騎士與物理**：披藍斗篷、戴寬帽、提燈籠的騎士騎乘棕馬（含馬鞍、韁繩與四肢步態），支援 Rapier3D WASM 物理與內建物理自動備援、預設自動沿小徑騎行並自動起跳跨過障礙、低幀率自動降解析度，以及全景巡遊模式。

## 操作方式
- **電腦**：`W A S D` 騎乘、`Shift` 奔跑、`Space` 跳躍、`T` 全景巡遊、滑鼠拖曳轉視角、滾輪縮放
- **手機**：左下虛擬搖桿、右下跳躍鈕、單指拖曳轉視角、雙指捏合縮放（支援實際裝置像素渲染）
